# Painel

Sistema base do tablet Lenovo Tab M10 Plus (3.ª geração, TB125FU, Android 13): launcher em Material 3,
tipografia Google Sans Flex, widgets de qualquer app e (Fase 2) um modo Display para a entrada de casa.

## Instalar

1. Abre a release **painel** deste repositório no tablet e descarrega o `Painel.apk`.
2. Instala (autoriza "fontes desconhecidas" para o browser, só da primeira vez).
3. Abre o Painel e toca em **Definir** no cartão do topo: o botão Home passa a abrir sempre o Painel.

Cada nova versão instala por cima da anterior (mesma chave), sem perder a configuração.

## Fase 1 (esta versão)

- Ecrã inicial com páginas, grelha configurável (4–8 colunas, 3–6 linhas) e dock.
- Widgets de qualquer app (Material You Widgets, Calendar, YouTube…): adicionar, mover, redimensionar.
- Gaveta de apps com pesquisa (deslizar para cima ou barra "Pesquisar apps"); ocultar, fixar na dock, desinstalar.
- Definições próprias: tema claro/escuro/sistema, cores do papel de parede ou cor principal, grelha, apps ocultas.
- Pastas circulares como no Pixel: no modo de edição arrasta uma app para cima de outra; toca para abrir, renomear e tirar apps.
- Ícones redondos como no Pixel (ou squircle/quadrado), ícones temáticos Material You, e editar nome e imagem de cada app.
- Papéis de parede originais ao estilo Pixel (5 estilos × 6 paletas), gerados no tablet, para o ecrã inicial e/ou de bloqueio.
- Ecrã de bloqueio do Painel: relógio grande (3 estilos), data e bateria; deslizar para cima desbloqueia.
- Desempenho: R8 + encolhimento de recursos, perfis de arranque (ProfileInstaller), sem serviços em segundo plano.

Gestos: toque longo num espaço vazio → menu (Widgets, Editar, Papel de parede, Definições);
toque longo num widget → modo de edição; no modo de edição arrasta para mover e usa o canto para redimensionar.
